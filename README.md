# Karriere Copilot

ИИ-агент для поиска **работы** и **Ausbildung** в Германии. Локальное веб-приложение
(Next.js): выбираешь цель → заполняешь поэтапную анкету («Не определился» есть почти
везде) → прикладываешь Lebenslauf → агент глубоко анализирует, запоминает тебя
(панель «Память агента»), задаёт уточняющие вопросы в чате → ищет реальные вакансии
в интернете (Легкий / Средний / MAX) и сортирует их по соответствию тебе.

> Для ИИ-модели, продолжающей разработку: полностью прочти [`HANDOVER.md`](./HANDOVER.md) —
> там архитектура, карта файлов, требования пользователя и правила, которые нельзя нарушать.

## Быстрый старт

```bash
bun install            # или npm install
cp .env.example .env   # заполни ИИ и поиск (см. ниже)
bunx prisma db push    # создать БД
bun run dev            # http://localhost:3000 (слушает только 127.0.0.1)
```

Приложению нужны **два внешних источника**, и без них оно скажет об этом прямо, а не сломается молча:

1. **ИИ.** Любой из вариантов:
   - в окне «ИИ-сервер» выбрать локальную Ollama / LM Studio или облако (GroqCloud, OpenRouter, свой сервер) — ключ хранится только в браузере;
   - или задать `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` в `.env` — это «встроенный» ИИ по умолчанию.
2. **Веб-поиск вакансий** (не зависит от выбранной модели): `SEARXNG_URL` (свой SearXNG, формат json включён) или
   `BRAVE_API_KEY`. Пример SearXNG: `docker run -d -p 8080:8080 searxng/searxng`.

В окне «ИИ-сервер» показывается, что из этого настроено.

## Обновление с прежней версии

После обновления выполни `bunx prisma db push` (добавляется необязательная колонка `intel`). Старые вакансии останутся.

## Что агент проверяет в вакансиях

Перед показом агент открывает каждую ссылку: неактуальные (404, истёкший срок, «Stelle besetzt») убираются,
у остальных видно, проверена ссылка или её нужно проверить самому. В карточке — срок подачи, требования, контакт и
способ подачи (если они есть на странице) и рекомендация, подходит ли вакансия именно тебе и что сделать перед откликом.
Сайты, блокирующие ботов, помечаются «ссылку проверь сам»: это не значит, что вакансия закрыта.

## Как агент ищет

- **Источники:** официальная биржа Arbeitsagentur (вакансии и Ausbildung с расстоянием) + веб-поиск по порталам и сайтам
  работодателей. Запросы строятся по шаблонам и дополняются ИИ.
- **Чистка:** соцсети, списки «1 234 вакансии…», статьи про зарплату и повторы убираются до анализа; одна вакансия
  на нескольких порталах показывается один раз; от одной компании не больше трёх.
- **Оценка** считается кодом по ступеням ИИ, расстоянию, свежести и надёжности источника — повторный поиск даёт
  сопоставимые числа. Результаты поиска кешируются на 6 часов (`SEARCH_CACHE_HOURS=0` отключает).

## Приватность и безопасность

- Анкета, текст документов, сообщения и поисковые запросы уходят выбранному ИИ-сервису и поисковому провайдеру.
  Для облачных вариантов это значит, что персональные данные покидают компьютер. Локальная модель
  (Ollama / LM Studio) оставляет их у тебя; наружу тогда идут только поисковые запросы.
- Данные хранятся в локальной SQLite (`db/custom.db`). SQL-запросы в логи не пишутся.
- `/api/*` отвечает только запросам с `localhost` / `127.0.0.1` и отклоняет запросы с чужого `Origin`.
  Другой адрес нужно явно добавить в `ALLOWED_HOSTS`.
- Страницы вакансий читаются напрямую только по публичным адресам (localhost и локальная сеть заблокированы).
